## D. Known Limitations

### Confirmed limitations

1. **Application implementation has not started in the inspected workspace.** `src/` contains only `.gitkeep`; no runnable application modules or automated test files were found. This is consistent with the stated analysis/design/planning stage and is **not a missing 24 October checkpoint deliverable**. The README says setup/run/test instructions will be added when runnable code exists.
2. **Most core documents remain templates or partial drafts.** The proposal, existing-system comparison, technology comparison, requirements, architecture description, and verification plan contain blank sections or matrices.
3. **User research is planned, not completed.** The relevance README says that no in-depth interviews have been conducted; the findings table and interview-record directory contain no completed interview results.
4. **The architecture work is incomplete.** One editable use-case diagram exists; system-context and component diagrams and readable diagram exports were not found.
5. **Prototype readiness is only partially established.** The Figma URL opens to metadata and a thumbnail showing several UI frames, but the interactive canvas rendered blank in this browser session. The five required scenarios and interactive behavior are therefore not verified. The remote `main` branch has a two-line [link note](https://github.com/iloveeroha/Diploma-Project-by-Jetibay-Sherkenov-Yessenbekov/blob/main/prototype/08-ux.md); the local workspace copy does not include that file, and no local exports were found.
6. **Testing and AI-quality evaluation are not evidenced.** The verification plan has no completed metrics or procedures, and the inspected workspace contains no tests, evaluation scripts, or measured results.
7. **Technical feasibility remains unverified.** The supervisor feedback identifies the hardware inventory and model feasibility spike as outstanding; no hardware table or spike results were found in the inspected files. No integrated ASR, diarization, summarization, or action-item extraction components were found.
8. **The seven D-08 PR deliverables and final supervisor confirmation are not complete or not verifiable.** Only PRs #1 and #2 were found merged. A direct commit adds a Figma URL but does not replace the missing required PRs. The final-check record is blank, the tags endpoint returned no tags, and the public branch-protection endpoint requires authentication.
9. **Local Git state is unavailable in this workspace.** The workspace has no `.git` directory, so a local branch, local changes, and correspondence between the workspace copy and a particular commit could not be confirmed. The remote history, PRs, and refs were checked separately.

### Potential risks requiring verification

- The Figma preview thumbnail is publicly accessible in this check, but the interactive player rendered blank. Verify it in a standard committee/browser session and click through each of the five documented UX flows.
- Model performance, local resource requirements, licensing/access conditions, and zero-egress behavior remain risks until measured and tested. No such tests are evidenced here.
- YouTrack currently marks LAM-6 and LAM-7 `Done`, but their described deliverables are not fully present in the repository. The task descriptions, ownership, and completion claims should be reconciled with the actual files and evidence.
- The branch-protection settings could not be inspected without authenticated repository-admin access; the HTTP 401 response is not proof that protection is absent.
- Several bibliography entries were spot-checked, but publisher access/rate limits prevented full source-by-source validation. Add the confirmed DOI to the Zhabayev–Tukeyev entry and complete the remaining checks before academic submission.
